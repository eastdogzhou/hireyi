## 🎯 项目概述

**AI Resume Manager Pro V2** 是一个完整的前端原型系统，专为 AI 驱动的简历管理场景设计。本版本采用专业的蓝色主题和现代化的设计语言，提供企业级的视觉体验。

### 核心价值

- ✅ **AI 智能解析**：自动识别简历中的关键信息
- ✅ **智能匹配算法**：基于职位要求计算候选人匹配度
- ✅ **完整面试流程**：从简历筛选到 Offer 发放的全流程管理
- ✅ **专业设计系统**：统一的蓝色主题，现代化 UI/UX

## 🚀 核心功能

### 1️⃣ 候选人管理模块

**候选人列表页 (01-candidates-list.html)**
- 🔍 **搜索功能**：支持姓名、技能关键词搜索
- 🎛️ **多维筛选**：状态、经验、期望薪资、投递时间
- 📊 **表格展示**：候选人基本信息、核心技能、状态标签
- 📤 **简历上传**：支持 PDF/Word 格式，AI 自动解析

**候选人详情页 (02-candidate-detail.html)**
- 👤 **基本信息**：头像、姓名、联系方式、期望薪资
- 💼 **工作经历**：公司、职位、时间、工作描述
- 🎓 **教育背景**：学校、专业、学历、毕业时间
- 🛠️ **技能清单**：技能标签，可视化展示
- 📅 **面试评估时间线**：完整的面试历程和反馈记录
- 🎯 **相关职位**：推荐匹配的职位列表

### 2️⃣ 职位管理模块

**职位列表页 (03-positions-list.html)**
- 📋 **职位卡片**：职位名称、部门、候选人统计
- 📈 **统计数据**：
  - 总候选人数
  - 面试中人数
  - 待发 Offer 人数
- 🏷️ **状态标识**：招聘中 / 已关闭
- 🔗 **快速操作**：查看详情、编辑职位

**职位详情页 (04-position-detail.html)**
- 📝 **职位信息卡片**：薪资范围、经验要求、工作地点
- 📄 **完整 JD**：
  - 岗位职责（详细列表）
  - 任职要求（详细列表）
  - 技能标签
- 🎯 **候选人匹配列表**：
  - **匹配度评分**：95分（极高）、88分（高度）、75分（中等）
  - 候选人基本信息
  - 核心技能标签
  - 工作经验和期望薪资
  - 当前状态
  - 操作按钮（查看详情、安排面试）
- 🔍 **搜索筛选**：按状态、匹配度、时间排序
- ⚡ **AI 智能筛选**：一键筛选最佳匹配候选人

### 3️⃣ 首页导航

**首页 (index.html)**
- 🎨 **Hero Section**：系统介绍和快速入口
- ✨ **核心功能特性**：AI 解析、智能匹配、面试评估
- 📦 **系统模块卡片**：候选人管理、职位管理
- 🛠️ **技术栈展示**：Tailwind CSS、HTML5、JavaScript

## 📖 使用指南

### 快速开始

1. **下载文件**
   - 从 AI Drive 下载完整项目文件夹
   - 或使用提供的下载链接

2. **本地预览**
   ```bash
   # 方法 1：使用 Python 内置服务器
   python -m http.server 8000
   
   # 方法 2：使用 Node.js http-server
   npx http-server -p 8000
   
   # 方法 3：直接用浏览器打开
   open index.html
   ```

3. **浏览页面**
   - 访问 `http://localhost:8000` 或直接打开 `index.html`
   - 点击导航按钮进入不同模块

### 页面导航路径

```
首页 (index.html)
├── 候选人管理
│   ├── 候选人列表 (01-candidates-list.html)
│   └── 候选人详情 (02-candidate-detail.html)
└── 职位管理
    ├── 职位列表 (03-positions-list.html)
    └── 职位详情 (04-position-detail.html)
```

### 交互功能

#### 候选人列表页
- 🔍 点击搜索框输入关键词
- 🎛️ 使用筛选器缩小范围
- 📤 点击"上传简历"按钮打开上传模态框
- 👁️ 点击候选人姓名跳转到详情页

#### 候选人详情页
- 📅 滚动查看完整面试评估时间线
- 🎯 点击相关职位卡片跳转到职位详情
- 🔙 点击面包屑导航返回列表

#### 职位列表页
- 🔍 使用搜索和筛选功能
- 📊 查看实时候选人统计数据
- 🔗 点击"查看详情"进入职位详情页

#### 职位详情页
- 📝 查看完整 JD 描述
- 🎯 浏览候选人匹配列表（按匹配度排序）
- ⚡ 点击"AI 智能筛选"进行智能筛选
- 📤 点击"上传简历"为该职位添加候选人
- 👁️ 点击候选人姓名跳转到候选人详情
