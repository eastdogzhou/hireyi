# AI 简历管理系统 - 前端架构设计

## 一、页面结构规划

### 1. 总体布局
```
┌─────────────────────────────────────────┐
│  侧边导航栏  │      主内容区           │
│             │                          │
│  - 人才库    │                          │
│  - 职位管理  │      页面内容             │
│             │                          │
└─────────────────────────────────────────┘
```

### 2. 核心页面（共 4 个主页面）

#### **页面 1：人才库列表** `/candidates`
**功能**：
- 展示所有候选人，支持搜索、筛选、分页
- 快速上传简历
- 查看候选人详情

**布局**：
```
┌──────────────────────────────────────────────┐
│  🔍 搜索框  | 筛选器(技能/评分/时间) | [上传简历] │
├──────────────────────────────────────────────┤
│  表格：                                       │
│  ┌────┬───────┬────────┬──────┬──────┬────┐ │
│  │ ID │ 姓名  │ 技能    │ 评分 │ 时间  │操作│ │
│  ├────┼───────┼────────┼──────┼──────┼────┤ │
│  │ 1  │ 张三  │ React.. │  3   │ 2天前 │查看│ │
│  │ 2  │ 李四  │ Python. │  4   │ 1周前 │查看│ │
│  └────┴───────┴────────┴──────┴──────┴────┘ │
│  分页: < 1 2 3 4 5 >                         │
└──────────────────────────────────────────────┘
```

**关键操作**：
- 点击"上传简历" → 打开上传弹窗 → AI 自动解析
- 点击"查看" → 跳转到候选人详情页
- 搜索：姓名模糊搜索、技能标签筛选
- 筛选：评分范围（1-4 分）、时间范围

## 二、页面间导航关系

```
人才库列表 ←→ 候选人详情 ←→ 职位详情
    ↓              ↓              ↑
    └──────────→ 职位列表 ←───────┘
```

**导航逻辑**：
1. 从**人才库列表**可以：
   - 查看候选人详情
   - 上传新简历

2. 从**候选人详情**可以：
   - 返回人才库列表
   - 点击关联职位跳转到职位详情
   - 添加面试评价

3. 从**职位列表**可以：
   - 查看职位详情
   - 创建新职位

4. 从**职位详情**可以：
   - 返回职位列表
   - 上传简历（自动关联）
   - 智能筛选（AI 匹配）
   - 点击候选人跳转到候选人详情

## 四、技术要点

### 1. **状态管理**
- 使用 **React Context** 或 **Zustand** 管理全局状态
- 候选人列表、职位列表缓存在客户端
- 搜索筛选条件保持在 URL 参数中（便于分享）

### 2. **数据交互**
```typescript
// 使用 Supabase Client 直接调用
import { supabase } from '@/lib/supabase'

// 获取候选人列表
const { data, error } = await supabase
  .from('candidates')
  .select('*')
  .order('created_at', { ascending: false })
  .range(0, 19)

// 复杂业务逻辑调用后端 API
const response = await fetch('/api/positions/1/screening', {
  method: 'POST',
  body: JSON.stringify({ limit: 100 })
})
```

### 3. **关键交互**
- **简历上传**：使用 `multipart/form-data` → 后端解析 → 返回结构化数据
- **智能筛选**：显示进度条（预筛选 → AI 打分 → 关联完成）
- **实时更新**：使用 Supabase Realtime 订阅数据变化（可选）

## 五、设计原则

### ✅ **简洁原则**
- 4 个核心页面覆盖所有功能
- 避免多层嵌套路由
- 弹窗处理次要操作（编辑、评价）

### ✅ **高效原则**
- 表格/卡片视图快速浏览
- 搜索筛选即时响应
- AI 功能一键触发

### ✅ **一致性原则**
- 统一的卡片样式
- 统一的评分展示（★★★☆）
- 统一的状态颜色（screening=蓝色、interview=黄色、offer=绿色）
