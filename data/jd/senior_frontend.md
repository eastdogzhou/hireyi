高级前端开发工程师（AI 应用方向）

任职要求：

- 本科及以上学历，计算机相关专业背景优先；
- 至少4年及以上前端开发经验，具备中大型项目研发或架构设计经验；
- 精通 HTML5、CSS3、JavaScript，熟练掌握 TypeScript，深入理解类型系统并能在项目中有效应用；
- 熟练掌握 React 或 Vue 等主流前端框架，理解其核心原理，具备组件化开发和工程实践能力；
- 熟悉模块化开发流程，掌握常用构建工具（如 Webpack、Vite 等），具备前端工程化实战经验；
- 具备丰富的性能优化经验，了解加载优化、渲染机制、交互性能等核心优化点；
- 熟悉 Git 工作流，具备 CI/CD、前端自动化测试相关经验；
- 具备良好的前后端协作能力，熟悉 RESTful 或 GraphQL 等主流接口设计与集成方式；
- 注重代码质量和可维护性，具备良好的系统设计思维与抽象能力；
- 具备良好的沟通协作能力，责任心强，自我驱动，有团队技术影响力。

加分项：

- 具备浏览器插件（如 Chrome / Edge Extension）开发和上线经验；
- 熟悉大模型（如 OpenAI）、MCP 协议、SSE（Server-Sent Events）等新型数据交互与 AI 应用场景；
- 熟悉 Node.js 后端开发，具备接口编写、服务部署及项目模块拆分经验；
- 熟悉无头浏览器相关技术（如 Puppeteer、Playwright、Selenium 等），能够应用于自动化测试、调试和数据采集等场景；
- 熟悉小程序相关生态，有实际小程序开发和上线经验；
- 有使用主流云平台（如 AWS、阿里云、腾讯云）或容器化技术（Docker / Kubernetes）进行部署和运维的经验；
- 有前端架构设计、性能治理、组件库开发等平台建设项目经验；
- 熟悉多语言、国际化（i18n/l10n）前端方案，具备海外/多地区系统支持经验；
- 拥有积极的技术影响力，如开源贡献、技术文章发表、行业技术分享或社区活跃表现；
- 关注前沿前端技术（如微前端、WebAssembly、PWA、Serverless 等），并具备实践或探索经验；
- 拥有良好的产品意识，能够从用户视角出发，推动体验优化并支持业务迭代。
